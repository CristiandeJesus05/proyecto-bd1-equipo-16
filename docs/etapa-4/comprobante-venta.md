## Casos de consulta-escenarios-posibles

* Ejercicio Nº 1: Clientes que más gastaron    
Crear una consulta que muestre el nombre, el apellido y el monto de las 3 compras más caras, es decir, los clientes que más gastaron. Ordenar el resultado de mayor a   menor monto

* Ejercicio Nº 2: Películas más vistas  
Crear una consulta que muestre, en una sola fila, la cantidad de entradas vendidas de cada película. Poner como alias de cada columna el título de la película    

* Ejercicio Nº 3: Recaudación por método de pago  
Crear una consulta que muestre, en una sola fila, el total recaudado con cada método de pago (Efectivo, Tarjeta de crédito, Tarjeta de débito, Transferencia y   Mercado Pago). Poner como alias de cada columna el nombre del método  
  
* Ejercicio Nª4: Detalle de una compra (comprobante)  
Mostrar el número de compra, fecha, cliente, método de pago, película, butaca y precio de cada entrada.  
  
* Ejercicio Nª5: Funciones programadas por película  
Mostrar el título de la película, fecha, horario, nombre de la sala y precio de cada función, ordenadas por fecha y horario. 
  
* Ejercicio Nª6: Historial de entradas por cliente  
Mostrar el ID del cliente, nombre completo, número de compra, fecha de compra, película y precio de cada entrada.
